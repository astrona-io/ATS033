# Authors and Maintainers

This course is created by Astrona.io.

Every copy and every modified version of this material must keep this file
and these names. The terms are in `NOTICE`.

Authors write the pages, labs and questions. Maintainers review changes,
answer issues and keep the labs working. One person can have both roles.
List each person once per role as `- Name (GitHub: handle)`. In the same pull
request, add them under "About the authors" in
`sections/intro/30-how-this-course-is-made.md`, with a 320 × 320 PNG photo in
`sections/intro/images/author/<handle>.png`. CONTRIBUTING.md shows the format.
CI checks that both list the same people.
