# Summary

Host network hardening starts with required component connections and the listeners that serve them. Binding, filtering and authenticated authorization address different aspects of exposure.

Allow necessary peers and return traffic while limiting unnecessary ingress and egress. Review IPv4, IPv6, overlays and durable configuration together; a blocked public port does not prove that an internal or node-local management path is protected.
