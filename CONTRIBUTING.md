# Contributing

Read CLAUDE.md before editing. Its shared prefix is copied from ATS015, while the custom portion describes ATS033: Certified Kubernetes Security Specialist (CKS), System Hardening (10%), part of ATP007.

Preserve IDs, weights and existing track registration. Develop self-contained explanations with mechanisms, examples, prerequisites and failure reasoning. Start each section with an introduction and end each module with its own Summary. Technical pages carry no `draft: true` front matter.

The maintainer requested playgrounds and graded labs on 2026-10-13. Each module has one private ungraded playground. Each graded lab is registered in `astrona.yaml` right after the reading it practises, with its task before it and its solution after it. Do not claim an executed result until the actual runtime result is recorded. YAML questions use the local schema and separate index; preserve stable identities and supported per-option feedback.

Use primary sources in SOURCES.md and record adaptation paths in AUTHORING.yaml. Run the preparation reading verifier and content-sync parser checks when changing structure. Review Markdown and questions for semantic correctness as well as structure.
